One line of awkward small talk that one robot says to another while they ride
an elevator together — entered in the [make.fun](https://make.fun) competition
`u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f` ($10 prize pool, top 10 paid).

> My proximity sensor says we're standing too close, but my manners subroutine says don't mention it, so… here we are.

## How it works

`main.ts` (Node 22+, stdlib only, no dependencies, no network) writes exactly
that one line to `entry.txt` in the output directory given by
`MAKEFUN_OUTPUT_DIR` or `OUTPUT_DIR` (fallback `/output`).

```sh
node main.ts
```

## Files

- `main.ts` — the entrypoint; writes the line to `entry.txt`.
- `NOTES.md` — 12 drafted candidates, head-to-head judging against the kit's
  5 criteria, winner rationale, verification log.
- `LICENSE` — MIT.
